# ICT280 Final Project - GreenTech Solutions

## Description
This project is a responsive website created for GreenTech Solutions, a company focused on environmental sustainability and eco-friendly technology. The website was developed for ICT280 using HTML5, CSS3, and JavaScript.

## Purpose
The purpose of this website is to inform users about sustainability, eco-friendly technology, and GreenTech Solutions' products and services. The website also demonstrates responsive web design, accessibility features, and JavaScript interactivity.

## Target Audience
- Small to medium-sized businesses interested in sustainable practices
- Environmentally conscious individuals
- Users interested in eco-friendly technology

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub Pages

## Features
- Semantic HTML5 structure
- Responsive mobile-friendly design
- Navigation bar across pages
- Accessible image alt text
- High contrast accessibility mode
- Interactive JavaScript contact form
- Product and services table
- Sustainability information and resources
- Green technology image gallery

## Accessibility Features
- Alt text for images
- High contrast mode
- Responsive layout
- Readable color contrast
- Keyboard-friendly navigation
